# My Week, My progress, Settings (#585)

iPhone 17 simulator (iOS 27), from `agent/585-week-progress-settings`. Sessions were seeded straight into the SwiftData store (14 days, 3 games) and each screen was opened with a temporary launch hook that is not in the PR. This is simulated data, not play through the UI.

- `h-en-light.png`: My Week, English, light, default text.
- `h-es-dark.png`: My Week, Spanish, dark, default text. The day chips (the only visual change) start at the bottom edge; their espresso outline is visible there.
- `p-es-dark-ax5.png`: My progress, Spanish, dark, maximum accessibility text (top of the screen; it scrolls).

Not captured: the scrolled day chips, Settings, iPhone SE, VoiceOver on a device.
